# Agent briefs

This folder is for the briefs given to AI subagents (the written task, rules and output format an agent starts from).
NouSR was built with AI agents under the maintainer's direction: the lead session runs on Claude Opus, subagents on
Sonnet and Haiku, and a Fable model has also done review. Each run is recorded in [../agent-ledger.md](../agent-ledger.md).

Briefs are kept public, next to the ledger, so the way agents were used can be checked and reused: contributors who work
with an agent can copy a brief's structure (tight scope, the files it may touch, the decision rules in
[CLAUDE.md](../../CLAUDE.md), and how it must report). Briefs are a record and are not edited afterwards.
